# C++ Data Structures

A collection of **C++ Data Structures implementations** developed through practical programming exercises. This repository covers fundamental and intermediate data structures, along with core concepts such as pointers, dynamic memory, recursion, searching, traversal, and file handling.

### Linked Lists

* Singly Linked List
* Doubly Linked List
* Circular Linked List

### Linear Data Structures

* Stack using Arrays
* Stack using Linked Lists
* Queue using Arrays
* Queue using Linked Lists

### Trees

* Binary Search Tree (BST)
* AVL Tree

### Other Data Structures

* Binary Heap
* Graph using Adjacency List
* Hash Table / Hashed Page Table

### Additional Implementations

* Developer–Project Management using linked lists
* Family Tree using child-sibling representation

## 🔍 Implementation Highlights

### Linked Lists

Implementations demonstrating insertion, deletion, traversal, searching, and navigation using different linked-list structures.

### Trees

Includes Binary Search Tree and AVL Tree implementations with tree insertion, searching, traversal, and balancing concepts.

### Graph

A graph implementation using an **adjacency-list representation** for storing relationships between connected vertices.

### Heap

A binary heap implementation demonstrating hierarchical data organization and heap-based operations.

### Hash Table

A hash-based implementation demonstrating key-to-address mapping and page-table style data organization.

### Family Tree

A tree-based application using **child-sibling representation**, recursive searching, preorder/postorder traversal, and file-based data storage.

### Developer–Project Management

A practical implementation combining linked-list structures to represent developers and their assigned projects.
